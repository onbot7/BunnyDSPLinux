Hardware Driver
Tanchjim Bunny DSP (KTMicro KT0210) 8-band hardware PEQ controller & WebHID bridge for Linux.
NixOS One-Liner (configuration.nix)
services.udev.extraRules = ''SUBSYSTEM=="hidraw", ATTRS{idVendor}=="31b2", ATTRS{idProduct}=="1112", MODE="0666", TAG+="uaccess"'';
Then run sudo nixos-rebuild switch (if extraRules already exists, append rule inside existing quotes).
Universal Setup (Ubuntu / Arch / Fedora / Debian / openSUSE / Void / Alpine)
sudo ./install-rules.sh --path
--path automatically symlinks tanchjim-ctl into /usr/local/bin so you can run it anywhere.
